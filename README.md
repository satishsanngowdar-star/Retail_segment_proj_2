📊 Retail Sales Power BI Dashboard

This project is a Retail Sales Analysis Dashboard built using Microsoft Power BI Desktop.
The dashboard helps analyze sales performance, customer behavior, and product trends using interactive visualizations.

📁 Project Overview

The goal of this project is to analyze retail sales data and generate insights such as:

Total Sales Performance

Order Trends

Top Selling Products

Regional Sales Distribution

Customer Demographics

🗂 Dataset

The dataset contains retail transaction data with the following columns:

Column	Description
Transaction ID	Unique order identifier
Date	Order date
Customer ID	Unique customer
Gender	Customer gender
Product Category	Product category
Product Name	Name of product
Quantity	Units purchased
Price per Unit	Price of product
Total Amount	Total order value
Location	Sales location
📌 Dashboard KPIs

The following Key Performance Indicators (KPI) are displayed at the top of the dashboard.

1️⃣ Total Sales

Total revenue generated from all orders.

Total Sales =
SUM(Sales[Total Amount])
2️⃣ Total Orders

Total number of unique orders.

Total Orders =
DISTINCTCOUNT(Sales[Transaction ID])
3️⃣ Average Order Value

Average revenue generated per order.

Average Order Value =
DIVIDE([Total Sales], [Total Orders])
📊 Dashboard Visualizations

The dashboard includes the following visualizations.

📈 Sales by Product Category

Chart Type: Bar Chart

Shows total sales generated by each product category.

Fields Used

Field	Value
Axis	Product Category
Values	Total Sales
📉 Monthly Sales Trend

Chart Type: Line Chart

Displays sales trends over time to identify seasonal patterns.

Fields Used

Field	Value
Axis	Date (Month)
Values	Total Sales
🌍 Sales by Location

Chart Type: Map Chart or Bar Chart

Shows regional distribution of sales across locations.

Fields Used

Field	Value
Location	City / Region
Values	Total Sales
🏆 Top 10 Products

Chart Type: Bar Chart

Shows the top 10 products by total sales.

Steps

Add a Bar Chart.

Axis → Product Name.

Values → Total Sales.

Apply Top N filter = 10 based on Total Sales.
